# ВИКИ HSR

ВИКИ HSR — учебный сайт-вики по Honkai: Star Rail, созданный на HTML, CSS и JavaScript без фреймворков.

## Назначение проекта

Проект представляет собой удобную для обучения базу данных, включающую:

- персонажей;
- световые конусы;
- наборы реликвий;
- инструмент для составления команды;
- информацию о проекте;
- форму обратной связи.

Сайт оформлен в тёмном игровом стиле и использует локальный набор данных в формате JSON.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- JSON

## Возможности

- адаптивная многостраничная вёрстка;
- динамическая загрузка данных с помощью `fetch()`;
- поиск и фильтры;
- сообщения для пустых результатов;
- конструктор команды с поддержкой перетаскивания;
- альтернативное управление командой щелчком или касанием;
- проверка формы и обработка отправки через `preventDefault()`;
- семантический HTML и видимые состояния фокуса для доступности.

## Структура проекта

- `index.html` — главная страница;
- `characters.html` — каталог персонажей;
- `lightcones.html` — каталог световых конусов;
- `relics.html` — страница наборов реликвий;
- `detail.html` — подробная информация о персонажах, световых конусах и наборах реликвий (параметры запроса `type` и `id`);
- `favorites.html` — избранное, сохранённое на устройстве;
- `teambuilder.html` — интерактивный конструктор команды;
- `about.html` — информация о проекте;
- `feedback.html` — форма обратной связи;
- `css/style.css` — стили сайта;
- `js/script.js` — загрузка данных и интерактивные функции;
- `data/data.json` — нормализованный набор данных для интерфейса;
- `data/entity-details.json` — локализованные данные StarRailRes о способностях, следах, эйдолонах, световых конусах, бонусах реликвий и предметах наборов, связанные по исходным ID;
- `assets/` — игровые изображения и значки из папки ресурсов проекта.

## Запуск проекта


Поскольку сайт загружает JSON с помощью `fetch()`, открывайте его через локальный HTTP-сервер.

Выполните команды:

```bash
cd "Viki-HSR"
python -m http.server 8000
```
Если верхняя команда не работает то пробуйте нижнюю команду

```bash
cd "Viki-HSR"
python -m http.server --bind localhost
```

Затем откройте в браузере:

http://localhost:8000/

## Источник данных

В качестве источника справочной информации и схемы именования ресурсов используется репозиторий StarRailRes. Локализованные подробные данные нормализованы из каталога `index_new/ru`, в том числе из файлов `characters.json`, `character_skills.json`, `character_skill_trees.json`, `character_ranks.json`, `light_cones.json`, `relic_sets.json` и `relics.json`. Исходные ID используются для сопоставления записей: отсутствующие сведения не выдумываются, а локальные изображения остаются связанными с соответствующими записями.

Исходные названия персонажей и предметов сохранены как варианты для поиска; в интерфейсе используются доступные русские названия. Значения Path и Element в нормализованном каталоге сохраняют идентификаторы StarRailRes и переводятся общими отображающими картами в `js/script.js`. Для форм Первопроходца источник использует подставляемое имя `{NICKNAME}`; каталог и локализованные описания показывают нейтральное название «Первопроходец», а не этот шаблон или английский псевдоним. Нормализованный набор подробных данных загружается только на странице конкретной записи. Каталоги и глобальный поиск не загружают и не отображают деревья следов во время ввода запроса.
